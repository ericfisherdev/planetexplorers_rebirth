<objective>
Implement mouse-controlled camera that follows the player with FPS-style look behavior (horizontal rotation, vertical pitch clamped).

Purpose: Camera control is essential for navigation and gives the player spatial awareness. The original game uses Camera Forge (CameraForge.CameraController) which is a complex node-based camera system with user variables, pose blending, and script modifiers. We create a straightforward third-person camera that provides the same user-facing behavior (mouse look, follow player) without the Camera Forge complexity. This can be swapped for Camera Forge later when the full system is restored.

Output: Camera follows player at a configurable offset, mouse X rotates horizontally (yaw), mouse Y rotates vertically (pitch) with clamping. Cursor locked during play. Escape unlocks cursor.
</objective>

  <action>
    Create a camera controller that provides the same user experience as the original Camera Forge-based system but with direct implementation.

    **Create `Assets/Scripts/Rebirth/Player/RebPlayerCamera.cs`:**
    - MonoBehaviour `RebPlayerCamera` in namespace `Pathea.Rebirth`
    - Attach to the Main Camera GameObject (or a new camera if none exists)

    **Public configuration fields:**
    - `Transform followTarget` -- the player transform to follow (set by RebGameStarter or found automatically)
    - `Vector3 offset = new Vector3(0f, 2.5f, -4f)` -- third-person offset behind and above player
    - `float mouseSensitivity = 2.5f` -- mouse look sensitivity (matches typical FPS defaults)
    - `float minPitch = -80f` -- minimum vertical angle (looking up)
    - `float maxPitch = 80f` -- maximum vertical angle (looking down)
    - `float followSmoothTime = 0.1f` -- smooth follow lag (SmoothDamp time)
    - `bool invertY = false` -- option to invert mouse Y axis
    - `float scrollZoomSpeed = 2f` -- mouse scroll to zoom in/out
    - `float minDistance = 1f` -- minimum zoom distance
    - `float maxDistance = 15f` -- maximum zoom distance

    **Private state:**
    - `float yaw` -- current horizontal rotation (degrees)
    - `float pitch` -- current vertical rotation (degrees)
    - `float currentDistance` -- current zoom distance from target
    - `Vector3 currentVelocity` -- for SmoothDamp

    **Awake():**
    - Initialize `currentDistance` from `offset.magnitude`
    - Initialize `yaw` and `pitch` from current camera rotation
    - If `followTarget` is null, try to find it: look for a GameObject with RebPlayerMotor component, or with tag "Player"

    **Start():**
    - Lock and hide cursor: `Cursor.lockState = CursorLockMode.Locked; Cursor.visible = false;`

    **LateUpdate():** (LateUpdate so it runs after player movement)
    - **Cursor toggle:** If `Input.GetKeyDown(KeyCode.Escape)`, toggle cursor lock. If cursor is unlocked, skip mouse look (but still follow player).
    - If `Input.GetMouseButtonDown(0)` and cursor is unlocked, re-lock cursor.
    - **Mouse look (only when cursor locked):**
      - `yaw += Input.GetAxis("Mouse X") * mouseSensitivity`
      - `pitch -= Input.GetAxis("Mouse Y") * mouseSensitivity * (invertY ? -1f : 1f)`
      - `pitch = Mathf.Clamp(pitch, minPitch, maxPitch)`
    - **Scroll zoom:**
      - `currentDistance -= Input.GetAxis("Mouse ScrollWheel") * scrollZoomSpeed`
      - `currentDistance = Mathf.Clamp(currentDistance, minDistance, maxDistance)`
    - **Calculate desired position:**
      - `Quaternion rotation = Quaternion.Euler(pitch, yaw, 0f)`
      - `Vector3 targetPoint = followTarget.position + Vector3.up * offset.y` (look at point is player + vertical offset for head height)
      - `Vector3 desiredPosition = targetPoint - rotation * Vector3.forward * currentDistance`
    - **Smooth follow:**
      - `transform.position = Vector3.SmoothDamp(transform.position, desiredPosition, ref currentVelocity, followSmoothTime)`
    - **Look at target:**
      - `transform.rotation = rotation` (direct rotation, not LookAt, to maintain exact pitch/yaw)
    - **Collision avoidance (basic):**
      - Raycast from targetPoint toward desiredPosition
      - If hit, move camera to hit point + small offset toward target (prevent clipping through walls)
      - `if (Physics.Raycast(targetPoint, desiredPosition - targetPoint, out RaycastHit hit, currentDistance)) { transform.position = hit.point + hit.normal * 0.2f; }`

    **Public methods:**
    - `void SetTarget(Transform target)` -- set followTarget and snap position immediately (no smooth)
    - `void LockCursor()` -- lock and hide cursor
    - `void UnlockCursor()` -- unlock and show cursor
    - `Quaternion GetFlatRotation()` -- returns `Quaternion.Euler(0, yaw, 0)` for use by movement system (camera-relative movement)

    **Integration note (comment in code):**
    - Document that RebPlayerMotor.cs uses `Camera.main.transform` for camera-relative movement, which will automatically pick up this camera's rotation.
    - Document that this replaces the PeCamera + CameraForge system temporarily. To restore original camera, remove this component and re-enable CameraForge.CameraController on the main camera.

    IMPORTANT: Use `Input.GetAxis("Mouse X")` and `Input.GetAxis("Mouse Y")` -- NOT `Input.mousePosition` delta. GetAxis provides raw mouse delta that works correctly with cursor lock.

    IMPORTANT: The camera must be on the same GameObject as Camera.main (or BE Camera.main) so that RebPlayerMotor's `Camera.main.transform` reference works for camera-relative movement.
