  <name>Task 1: Install Unity 6 and open the project</name>
  <action>
The user must install Unity Hub and Unity 6000.3 LTS, then open the project.
  </action>
  <verify>
**Prerequisites (one-time setup):**
1. Install Unity Hub: `yay -S unityhub` (Arch Linux)
2. Open Unity Hub, sign in or create Unity account
3. Go to Installs > Install Editor > select **Unity 6.3 LTS (6000.3.x)**
4. Include modules: **Linux Build Support (IL2CPP)** and **Windows Build Support (Mono)**
5. Wait for installation to complete

**Open the project:**
1. In Unity Hub, click "Open" > navigate to the project root directory
2. Unity will detect the version mismatch and ask to upgrade -- confirm
3. When prompted about the API Updater, click **"I Made a Backup. Go Ahead!"**
4. Wait for import to complete (may take several minutes for ~2,888 scripts + 197 shaders)

**What to check in the Console:**
- **EXPECTED:** Hundreds of compilation errors from missing proprietary plugins (NGUI, uLink, uLobby, FMOD, FinalIK, etc.) -- these are Phase 2 scope, ignore them
- **NOT EXPECTED:** Import-blocking errors that prevent the editor from opening (shader import failures, asset database corruption, crash on startup)
- **VERIFY:** The editor is open and responsive, you can navigate the Project window and see Assets/

**After API Updater runs:**
- The API Updater may show a dialog listing files it updated (component accessor conversions)
- Accept all changes

**Re-add scene list to Build Settings:**
1. Go to File > Build Settings
2. Add scenes in this order (from `.planning/phases/01-unity-6-migration/scene-list-backup.txt`):
   - Assets/Scenes/GameStart.unity
   - Assets/Scenes/GameRoleCustom.unity
   - Assets/Scenes/GameMainMenu.unity
   - Assets/Scenes/GameLobby.unity
   - Assets/Scenes/MLoginScene.unity
   - Assets/Scenes/PeGame.unity
   - Assets/Scenes/Intro.unity
   - Assets/Scenes/GameTheEnd.unity
   - Assets/Scenes/GameCredits.unity
   - Assets/Scenes/GameED.unity
3. Verify GameStart.unity is at index 0

<task type="auto">
  <name>Task 2: Post-editor-open grep verification</name>
  <files>None (read-only verification)</files>
  <read_first>
    ProjectSettings/ProjectVersion.txt
  </read_first>
  <action>
After the user confirms the editor opened successfully, run the following verification commands to confirm the migration is complete:

```bash
# 1. Verify ProjectVersion.txt updated to Unity 6
cat ProjectSettings/ProjectVersion.txt
# Should show 6000.3.x (not 5.2.4f1)

# 2. Verify no UnityScript files remain
find Assets/ -name "*.js" -not -name "*.json" | wc -l
# Should return 0

# 3. Verify no Application.LoadLevel remains
grep -r "Application\.LoadLevel" Assets/ --include="*.cs" | grep -v "//" | wc -l
# Should return 0

# 4. Verify no legacy particle classes remain
grep -r "\bParticleEmitter\b\|\bParticleAnimator\b" Assets/ --include="*.cs" | grep -v "//" | wc -l
# Should return 0

# 5. Verify no kernel32.dll P/Invoke remains
grep -r "kernel32\.dll" Assets/ --include="*.cs" | wc -l
# Should return 0

# 6. Verify no WWW class usage remains
grep -r "\bnew WWW(" Assets/ --include="*.cs" | wc -l
# Should return 0

# 7. Verify ProjectSettings were regenerated
ls ProjectSettings/*.asset | wc -l
# Should be > 0 (Unity regenerated them)

# 8. Check if API Updater converted component accessors
# These should now be GetComponent<Rigidbody>() etc.
# Some may remain if the updater missed them -- log count
grep -r "\.rigidbody\b" Assets/ --include="*.cs" | grep -v "GetComponent" | grep -v "//" | wc -l
grep -r "\.collider\b" Assets/ --include="*.cs" | grep -v "GetComponent\|hitInfo\|raycastHit\|hit\.\|collision\." | grep -v "//" | wc -l
```

If any of checks 2-6 return non-zero, investigate and fix the remaining occurrences. If check 8 shows remaining component accessors the API Updater missed, fix them manually with GetComponent<T>() calls.
  </action>
