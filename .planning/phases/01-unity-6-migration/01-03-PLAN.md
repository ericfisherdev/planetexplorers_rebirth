| Old Pattern | New Pattern | Notes |

| `emitter.minEnergy` / `emitter.maxEnergy` | `var main = ps.main; main.startLifetime = new ParticleSystem.MinMaxCurve(min, max);` | |
| `emitter.worldVelocity` | `var vel = ps.velocityOverLifetime; vel.x = ...; vel.y = ...; vel.z = ...;` | |

| Field declarations `ParticleEmitter someField` | `ParticleSystem someField` | |

**Step 1: Find all affected files.**
```bash
grep -rn "FindObjectsOfType\|FindObjectOfType" Assets/ --include="*.cs"
```

Research identified 18 occurrences in 9 files.

**Step 2: Apply these replacements in each file:**

| Old Pattern | New Pattern |
|-------------|-------------|
| `FindObjectsOfType<T>()` | `FindObjectsByType<T>(FindObjectsSortMode.None)` |
| `FindObjectsOfType(typeof(T))` | `FindObjectsByType(typeof(T), FindObjectsSortMode.None)` |
| `FindObjectOfType<T>()` | `FindFirstObjectByType<T>()` |
| `FindObjectOfType(typeof(T))` | `FindFirstObjectByType(typeof(T))` |
| `GameObject.FindObjectsOfType<T>()` | `GameObject.FindObjectsByType<T>(FindObjectsSortMode.None)` |
| `Object.FindObjectsOfType<T>()` | `Object.FindObjectsByType<T>(FindObjectsSortMode.None)` |

Use `FindObjectsSortMode.None` for all replacements -- it is the fastest option and the original code did not rely on any particular ordering (Unity 5 FindObjectsOfType had undefined order anyway).

**CAUTION:**
- Do NOT replace occurrences inside comments or strings
- Watch for the singular `FindObjectOfType` (no 's') vs plural `FindObjectsOfType` -- they have different replacements
- Some occurrences may be inside methods of proprietary plugin classes that won't compile anyway -- still replace them so the API call itself is correct when stubs are added in Phase 2
