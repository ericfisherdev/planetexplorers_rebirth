    LZ4 block format specification:
    - LZ4 is a byte-oriented, streaming compression algorithm
    - Each sequence: token byte (4 bits literal length + 4 bits match length), optional extra literal length bytes, literal bytes, 2-byte little-endian offset, optional extra match length bytes
    - Token high nibble: literal count (0-14 direct, 15 = read more bytes until byte < 255)
    - Token low nibble: match length - 4 (0-14 direct, 15 = read more bytes until byte < 255, minimum match = 4)
    - Match offset: 2 bytes little-endian, backward reference distance

    Implement the compressor using a hash table (64KB, 4-byte entries) for match finding, with a greedy match strategy. This is the standard LZ4 approach and matches the native library's behavior.

    The decompressor reads tokens and copies literals and matches.
