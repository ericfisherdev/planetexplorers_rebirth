<objective>
Force CPU-only terrain surface extraction and wire managed LZ4 for terrain data loading.

Purpose: The Voxelform2 terrain system depends on two native libraries that are not in the repo: OpenCLNet (GPU marching cubes) and lz4_dll (terrain data compression). The CPU marching cubes fallback already exists in the codebase (SurfExtractorCpuMC), but the OpenCL initialization path must be neutralized so it always falls through to CPU. The LZ4 native P/Invoke calls must be replaced with the managed C# LZ4 implementation created in Phase 2.

Output: Terrain surface extraction initializes without OpenCL errors; terrain data can be loaded/compressed via managed LZ4.
</objective>
