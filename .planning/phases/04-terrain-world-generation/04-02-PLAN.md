<objective>
Get Voxelform2 procedural terrain generating and rendering visible chunk meshes.

Purpose: This is the core of Phase 4 -- making terrain visible. The Voxelform2 system has a complete procedural terrain pipeline: VFDataRTGen generates voxel density data from noise functions, the LOD octree manages spatial subdivision, SurfExtractorCpuMC runs marching cubes to produce mesh vertices, and VFVoxelChunkGo creates Unity GameObjects with MeshFilter/MeshRenderer. With the OpenCL and LZ4 dependencies resolved in Plan 01, this plan focuses on ensuring the initialization flow works end-to-end so terrain actually appears.

Output: Running a "random map" new game produces visible terrain meshes in the Unity editor.
</objective>
