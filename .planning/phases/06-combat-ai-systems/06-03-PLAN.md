Key context: The projectile system is fully in the repo under `Assets/Scripts/AiScripts/Projectile/`. There are ~45 files covering various projectile types (bullets, arrows, cannonballs, lasers, missiles, shockwaves) and trajectory types (straight, parabolic, raycast, tracking, multi-target).

The flow is: Skill execution -> `ProjectileBuilder.Create()` -> instantiates `Projectile` prefab -> attaches `Trajectory` subclass (TRStraight for bullets, TRParabola for arrows) -> `Projectile.Update()` moves along trajectory -> on collision with target collider -> `SkProjectile` routes damage to target's `SkEntity`.

`SkProjectile` bridges the projectile system to the SkillSystem — it carries the attacker's `SkEntity` reference and the damage data from the skill definition.

Many projectile types exist for variety (PR = Projectile type, TR = Trajectory type, SPG = SkProjectile Group type). For Phase 6, focus on getting the CORE path working: `PRBullet` + `TRStraight` (straight bullets) and `PRArrow` + `TRParabola` (arcing arrows). The exotic types (lasers, missiles, torpedoes) can be verified later.
</context>
