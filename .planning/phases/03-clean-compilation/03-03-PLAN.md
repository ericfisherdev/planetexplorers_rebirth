  <action>
This task is inherently iterative. The approach:

1. **Trigger compilation** by opening the project in Unity 6 editor or by running the Unity compiler from CLI if available. If the project is already open, force a recompile via Assets > Reimport All or by editing and saving a .cs file.

2. **Read the Console output.** Copy all error messages. Categorize them:
   - **CS0246 (type not found):** Missing type that a Phase 2 stub should have defined. Fix by adding the missing type to the appropriate stub file, or if it's a type from a Unity package, add it to `Assets/Scripts/Stubs/`.
   - **CS1061 (member not found):** A stub type is missing a property/method/field that code accesses. Fix by adding the missing member to the stub class.
   - **CS0117 (no member in type):** Same as CS1061 but for static members.
   - **CS0103 (name not found):** Missing variable/constant. Usually a missing enum value or static field in a stub.
   - **CS0029/CS0030 (type conversion):** Implicit/explicit conversion missing. Fix by adding cast operators or conversion methods to stubs.
   - **CS0535 (interface not implemented):** Stub class inherits an interface but doesn't implement all members. Fix by implementing the missing interface members.
   - **CS0234 (namespace member not found):** Missing type in a namespace. Fix by adding the type to the stub namespace.
   - **CS0619/CS0618 (obsolete API):** Deprecated Unity API used. Replace with modern equivalent.
   - Other errors: Read the error, understand the root cause, fix minimally.

3. **Fix errors in batches.** Group errors by category and fix all instances of a category at once rather than one-by-one. Common batch fixes:
   - "Add missing property X to stub class Y" (may fix 10-50 errors at once)
   - "Add missing enum value Z to enum W" (may fix 5-20 errors)
   - "Add using statement for namespace N" (may fix all errors in a file)

4. **Do NOT modify game logic.** Only modify:
   - Stub files (add missing members)
   - Using directives (add missing imports)
   - Preprocessor blocks (fix conditional compilation)
   - Type casts (add explicit casts where needed)
   - Obsolete API calls (replace with modern equivalents)

5. **Track progress.** After each batch fix, recompile and count remaining errors. Continue until zero.

6. **Common Unity 5 to 6 compilation issues to watch for:**
   - `UnityEngine.Renderer.useLightProbes` removed (use `UnityEngine.Renderer.lightProbeUsage`)
   - `Physics.OverlapSphere` signature changes
   - `ParticleSystem.startColor/startSize/startLifetime` replaced with `main.startColor` etc.
   - `AudioClip.isReadyToPlay` removed
   - `EditorStyles` property changes
   - Component accessor shortcuts removed (`.rigidbody`, `.collider` etc. — Unity API Updater should handle these but may miss some)

7. **If errors exceed 200:** Focus on the highest-impact fixes first (a single stub fix that resolves 50+ errors). Document remaining errors for a gap closure plan if needed.
