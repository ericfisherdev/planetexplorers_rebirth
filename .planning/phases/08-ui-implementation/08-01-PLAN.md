<objective>
Create functional uGUI bridge implementations for all NGUI stub types used across the 417 NGUI-dependent files. These bridge classes replace the empty NGUI stubs (created in Phase 2) with real uGUI-backed implementations so that existing game scripts work without modification.

Purpose: This is the foundation for ALL UI work in Phase 8. Without functional NGUI types, none of the game's UI scripts can render anything. The bridge layer makes NGUI types thin wrappers around Unity's built-in uGUI (Canvas, Image, Text/TMP, Button, Slider, etc.).

Output: A complete NGUIBridge assembly that makes the codebase's 417 NGUI-dependent files functional.
</objective>

Key NGUI types used in codebase (from grep analysis):
- UILabel (text display) - used in nearly every UI file
- UISprite / UIFilledSprite / UISlicedSprite (image display) - used for icons, bars, backgrounds

- UISlider / UIProgressBar (value bars) - used for health, stamina, crafting progress
- UIInput (text input) - used for name entry, search, chat

- UIGrid / UITable (layout) - used for item grids, lists
- UIScrollView / UIScrollBar (scrollable content) - used for inventory, lists
- UIPanel (container with clipping/alpha) - used everywhere for grouping
- UIWidget (base with depth/alpha) - base class for all NGUI widgets
- UITexture (raw texture display) - used for minimap, portraits
- UICamera (event system) - used for UI raycasting
- UIRoot (canvas scaling) - used for resolution adaptation
- UIAnchor (positioning) - used for screen-relative positioning
- UIAtlas (sprite atlas) - used for sprite name lookups
- UIFont (font wrapper) - used by UILabel
- UIEventListener (event delegation) - used for onClick, onHover, etc.
- TweenPosition / TweenScale / TweenAlpha / TweenColor (animations) - used for UI transitions
- UITweener (animation base) - base class for all tweens

    **NGUIBridgeCore.cs:** Define shared enums and base types that NGUI code references:
    - `UIWidget.Pivot` enum (TopLeft, Top, TopRight, Left, Center, Right, BottomLeft, Bottom, BottomRight)
    - `UIPanel.RenderQueue` enum
    - `UIBasicSprite.Type` enum (Simple, Sliced, Tiled, Filled)
    - `UIBasicSprite.FillDirection` enum (Horizontal, Vertical, Radial90, Radial180, Radial360)
    - `UIBasicSprite.Flip` enum (Nothing, Horizontally, Vertically, Both)

    **UIWidgetBridge.cs:** `UIWidget : MonoBehaviour` -- base class for all NGUI widgets.
    - Properties: `alpha` (float, get/set -- controls CanvasGroup alpha if present), `depth` (int, controls sibling index), `width`/`height` (int, get/set -- maps to RectTransform sizeDelta), `pivot` (UIWidget.Pivot), `color` (Color), `isVisible` (bool), `cachedTransform` (Transform).
    - On Awake, ensure a RectTransform exists. Cache references.
    - `MakePixelPerfect()` -- no-op stub.
    - `SetDirty()` -- no-op stub.

    **UIPanelBridge.cs:** `UIPanel : UIWidget`
    - Properties: `clipping` (UIDrawCall.Clipping enum -- None, TextureMask, SoftClip, ConstrainButDontClip), `clipOffset` (Vector2), `clipRange` (Vector4), `clipSoftness` (Vector2), `baseClipRegion` (Vector4).
    - Back with a `RectMask2D` or `Mask` component for clipping. When `clipping` is set to SoftClip, add/enable `RectMask2D`; when None, remove/disable it.
    - Static `Find(Transform)` method that walks up parents looking for UIPanel.

    **UIAnchorBridge.cs:** `UIAnchor : MonoBehaviour`
    - Properties: `container` (GameObject), `side` (Side enum), `relativeOffset` (Vector2), `pixelOffset` (Vector2).
    - In LateUpdate, position self relative to container based on side/offset. For now, this can be a lightweight no-op since uGUI anchoring handles this natively.

    **UIEventListenerBridge.cs:** `UIEventListener : MonoBehaviour`
    - Delegates: `VoidDelegate(GameObject go)`, `BoolDelegate(GameObject go, bool state)`, `FloatDelegate(GameObject go, float delta)`, `VectorDelegate(GameObject go, Vector2 delta)`, `ObjectDelegate(GameObject go, GameObject obj)`, `KeyCodeDelegate(GameObject go, KeyCode key)`, `StringDelegate(GameObject go, string text)`.
    - Fields: `onSubmit`, `onClick`, `onDoubleClick`, `onHover`, `onPress`, `onSelect`, `onScroll`, `onDragStart`, `onDrag`, `onDragOver`, `onDragOut`, `onDragEnd`, `onDrop`, `onKey`, `onTooltip`, `onInput`.
    - Static `Get(GameObject go)` method -- returns existing or adds new UIEventListener.
    - Implement IPointerClickHandler, IPointerEnterHandler, IPointerExitHandler, IPointerDownHandler, IPointerUpHandler, IDragHandler, IBeginDragHandler, IEndDragHandler, IDropHandler, IScrollHandler from UnityEngine.EventSystems to fire the delegates.

    **TweenBridge.cs:** Define all tween classes that the codebase references:
    - `UITweener : MonoBehaviour` -- base with `from`, `to`, `duration`, `delay`, `style` (Once, Loop, PingPong), `onFinished` (List of EventDelegate), `enabled`, `PlayForward()`, `PlayReverse()`, `ResetToBeginning()`, `tweenFactor` (float 0-1).
    - `TweenPosition : UITweener` -- tweens RectTransform.anchoredPosition from `from` (Vector3) to `to` (Vector3).
    - `TweenScale : UITweener` -- tweens transform.localScale.
    - `TweenAlpha : UITweener` -- tweens CanvasGroup.alpha (adds CanvasGroup if missing).
    - `TweenColor : UITweener` -- tweens Graphic.color.
    - `TweenRotation : UITweener` -- tweens transform.localEulerAngles.
    - `TweenWidth : UITweener` -- tweens UIWidget.width.
    - `TweenHeight : UITweener` -- tweens UIWidget.height.
    - `EventDelegate` class with `Execute()`, `Add(List, EventDelegate.Callback)`, `Remove(List, EventDelegate.Callback)`, `IsValid` property, `Callback` delegate. This is NGUI's event wiring system.
    - All tweens use coroutine-based lerp in Update. `style` controls looping behavior.
    - Static helper: `TweenPosition.Begin(GameObject, float duration, Vector3 to)`, same pattern for all tween types.
