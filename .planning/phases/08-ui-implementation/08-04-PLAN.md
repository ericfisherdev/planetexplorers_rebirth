<task type="auto">
  <name>Task 2: Drag-and-Drop System for Inventory and Equipment</name>
  <files>
    Assets/Scripts/UI/Inventory/InventoryDragDrop.cs
  </files>
  <action>
    **InventoryDragDrop.cs:** Static/singleton class managing drag-and-drop state for the inventory system.

    - State: `m_IsDragging` (bool), `m_DraggedSlot` (InventorySlot), `m_DragIcon` (Image -- floating icon that follows cursor), `m_SourceType` (enum: Inventory, Equipment), `m_SourceIndex` (int).

    - On drag start (called from InventorySlot.OnBeginDrag):
      1. If slot is empty, cancel drag (return).
      2. Store source slot reference, source type, and source index.
      3. Create a floating drag icon: new GameObject with Image component, parent to Canvas root (so it renders on top), set sprite to the dragged item's icon, size 56x56, alpha 0.8.
      4. Set m_IsDragging = true.

    - On drag (called from InventorySlot.OnDrag):
      1. Move drag icon to follow cursor position (Input.mousePosition, convert via RectTransformUtility.ScreenPointToLocalPointInRectangle).

    - On drag end (called from InventorySlot.OnEndDrag):
      1. Destroy drag icon.
      2. If not dropped on a valid target, return item to source slot (no-op).
      3. Set m_IsDragging = false.

    - Drop handling -- register drop targets:
      1. **Inventory slot drop**: Swap items between source and target slots. If target is empty, move item. If target is occupied, swap both items.
      2. **Equipment slot drop**: If source is inventory and target is equipment slot, attempt equip. Check slot compatibility (e.g., weapon only in weapon slot). If incompatible, bounce back with brief red flash on equipment slot.
      3. **Equipment to inventory drop**: If source is equipment slot and target is inventory slot, unequip item and place in inventory.

    - Visual feedback:
      - Valid drop target: highlight slot border green when drag icon hovers over it.
      - Invalid drop target: highlight slot border red briefly.
      - Use IPointerEnterHandler/IPointerExitHandler on slots to detect hover during drag.

    - Integration with game systems: After successful equip/unequip/swap, attempt to call corresponding methods on `PackageCmpt` / `EquipmentCmpt`. If stubs, only update visual state (acceptable for this phase).

    - Edge cases:
      - Dragging outside the inventory window: cancel drag, return item.
      - Dragging stacked items: move the entire stack (split functionality deferred).
      - Double-clicking an item in inventory: auto-equip if it's equippable, otherwise no action.
  </action>
