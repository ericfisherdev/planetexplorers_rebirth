    **MainMenuController.cs:** MonoBehaviour that manages the main menu screen.
    - Singleton pattern (static Instance).
    - On Awake: find or create a Canvas (Screen Space - Overlay, sort order 100), add CanvasScaler (Scale With Screen Size, 1920x1080 reference, Match Width Or Height 0.5).
    - Create menu layout programmatically in `Start()`:
      1. Background panel (full-screen dark Image, color rgba(0.05, 0.05, 0.1, 1))
      2. Title text: "Planet Explorers" using TextMeshProUGUI, centered top third, font size 72, white
      3. Subtitle: "Rebirth" smaller below title, font size 36, light gray
      4. Button container: VerticalLayoutGroup centered in screen, spacing 20
      5. Three buttons: "New Game", "Load Game", "Quit" -- each 300x60 pixels with dark background and white text
    - Wire button clicks to MainMenuButtons methods.
    - Add a `savedGamesPanel` (initially hidden) for the Load Game list.
    - When Load Game is clicked, query `ArchiveMgr` for saved games. If no saves exist, show "No saved games found" message. If saves exist, list them as clickable entries that call the load flow.

    **MainMenuButtons.cs:** Static class with button handler methods.
    - `OnNewGame()`: Call `PeGameMgr.playerType = PeGameMgr.EPlayerType.Single;` then `PeFlowMgr.Instance.LoadScene(PeFlowMgr.EPeScene.SingleAdventure);` (or the appropriate scene enum for new single-player game). Wrap in try/catch -- if PeFlowMgr or PeGameMgr are not yet available (stubs), log warning and show "Game systems not ready" message.
    - `OnLoadGame(int archiveIndex)`: Call `ArchiveMgr` to load the specified archive, then transition to game scene.
    - `OnQuit()`: Call `Application.Quit();` and `#if UNITY_EDITOR UnityEditor.EditorApplication.isPlaying = false; #endif`.
    - `OnBackToMenu()`: Hide save list panel, show main buttons.

    IMPORTANT: Guard all calls to game systems (PeFlowMgr, PeGameMgr, ArchiveMgr) with null checks since they may still be stubs at this phase. Show user-friendly error messages if systems are unavailable.

    Follow existing codebase conventions: PascalCase methods, m_ prefix for private fields, singleton pattern matching `Singleton<T>` from Assets/Scripts/Assist/.
